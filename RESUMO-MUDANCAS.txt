═══════════════════════════════════════════════════════════════
  🚀 COMO COMEÇAR (PASSO A PASSO)
═══════════════════════════════════════════════════════════════

1️⃣ INSTALAR (se ainda não instalou):
   
   npm install

2️⃣ CONFIGURAR:
   
   Copy-Item env.example.txt .env
   
   Depois edite o .env com suas credenciais da Twitch

3️⃣ INICIAR:
   
   npm start

4️⃣ FAZER LOGIN (primeira vez):
   
   Abra: http://localhost:3000/auth/login
   
   Depois reinicie o servidor

5️⃣ 🧪 TESTAR (IMPORTANTE!):
   
   Abra: http://localhost:3000/test
   
   ⭐ SEMPRE TESTE AQUI PRIMEIRO! ⭐
   
   - Digite um texto
   - Clique em "Testar Áudio"
   - Deve ouvir o som
   
   ✅ Funcionou? Continue!
   ❌ Não? Veja os logs na página

6️⃣ CONFIGURAR NO OBS:
   
   - Adicionar > Browser Source
   - URL: http://localhost:3000/player.html
   - Largura: 800, Altura: 600
   - ✅ Marcar: "Controlar áudio via OBS"
   
   IMPORTANTE:
   - Botão direito na fonte > Interagir
   - Clicar em "Ativar Áudio"
   - Fechar a janela

7️⃣ TESTAR NO TWITCH:
   
   No chat: !fala Olá, teste de áudio!

═══════════════════════════════════════════════════════════════
  ❌ PROBLEMAS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════

1. ÁUDIO NÃO TOCA:

   Causa: Autoplay bloqueado
   
   Solução:
   → Teste em http://localhost:3000/test
   → Se funciona lá, problema é no OBS
   → No OBS: Botão direito > Interagir > Ativar Áudio
   → Reinicie a fonte do navegador se necessário

2. BOT NÃO CONECTA:

   Causa: Sem autenticação OAuth
   
   Solução:
   → Acesse http://localhost:3000/auth/login
   → Autorize a aplicação
   → Reinicie o servidor
   → Verifique arquivo .twitch-tokens.json

3. COMANDO !FALA NÃO FUNCIONA:

   Causa: Bot não está conectado ou cooldown
   
   Solução:
   → Veja logs do servidor (deve mostrar "Bot conectado")
   → Aguarde 3 segundos entre comandos
   → Verifique se escreveu corretamente: !fala (não !speak)

4. GOOGLE TRANSLATE BLOQUEADO:

   Causa: Região ou firewall
   
   Solução:
   → Use o player nativo: /player-native.html
   → Funciona offline, usa voz do sistema
