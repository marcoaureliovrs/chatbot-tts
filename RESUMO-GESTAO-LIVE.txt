  📋 RESUMO EXECUTIVO

Foi implementado um sistema completo de gestão de live integrado ao dashboard
do TTS Bot, permitindo controlar aspectos importantes da transmissão sem sair
do OBS ou abrir múltiplas abas.

═══════════════════════════════════════════════════════════════════════════════
  ✨ FUNCIONALIDADES IMPLEMENTADAS
═══════════════════════════════════════════════════════════════════════════════

1. 🎬 CRIAR CLIPS
   - Cria clips automaticamente com nome baseado em data/hora
   - Link direto para edição
   - Funciona apenas quando ao vivo
   
2. 📺 RODAR COMERCIAIS
   - 6 durações disponíveis (30s, 60s, 90s, 120s, 150s, 180s)
   - Mostra cooldown entre comerciais
   - Funciona apenas quando ao vivo

3. 📝 ALTERAR TÍTULO
   - Atualiza título da live (máximo 140 caracteres)
   - Contador de caracteres em tempo real
   - Funciona mesmo offline

4. 🎮 ALTERAR CATEGORIA/JOGO
   - Busca de categorias por nome
   - Visualização com thumbnail
   - Funciona mesmo offline

5. 🔄 INFORMAÇÕES DA STREAM
   - Status (ao vivo/offline)
   - Número de viewers (se ao vivo)
   - Título e categoria atuais
   - Tempo de transmissão (uptime)
   - Idioma da stream

  🔐 SISTEMA DE PERMISSÕES INCREMENTAIS
═══════════════════════════════════════════════════════════════════════════════

IMPORTANTE: O sistema NÃO invalida tokens existentes!

✅ Você pode continuar usando o bot com permissões básicas
✅ Solicite novas permissões apenas quando quiser usar recursos avançados
✅ Processo totalmente seguro e reversível

SCOPES BÁSICOS (já configurados):
  - chat:read    → Ler chat
  - chat:edit    → Enviar mensagens

SCOPES ADICIONAIS (para gestão de live):
  - clips:edit                 → Criar clips
  - channel:manage:broadcast   → Alterar título/categoria
  - channel:edit:commercial    → Rodar comerciais

═══════════════════════════════════════════════════════════════════════════════
  🚀 COMO COMEÇAR A USAR
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Inicie o servidor
  > npm start

PASSO 2: Abra o dashboard
  > http://localhost:3000

PASSO 3: Role até "📡 Gestão de Live"
  (localizado na parte inferior do dashboard)

PASSO 4: Verifique o status de permissões
  - Se mostrar ❌ em alguma permissão, clique em:
  
  [🔐 Solicitar Novas Permissões]

PASSO 5: Complete o OAuth
  - Uma janela da Twitch será aberta
  - Faça login (se necessário)
  - Autorize as novas permissões
  - Aguarde confirmação

PASSO 6: Use as funcionalidades!
  - Os botões serão habilitados automaticamente
  - Clique nas funcionalidades desejadas
  - Tudo será atualizado na Twitch em tempo real

  🔧 DETALHES TÉCNICOS

NOVAS FUNÇÕES DA API (src/twitch-api.js):
  - twitchApiRequestWithBody()   → Requisições POST/PATCH
  - createClip()                 → Criar clips
  - getStreamInfo()              → Info da stream ao vivo
  - getChannelInfo()             → Info do canal
  - updateStreamTitle()          → Atualizar título
  - updateStreamCategory()       → Atualizar categoria
  - searchCategories()           → Buscar jogos/categorias
  - runCommercial()              → Rodar comerciais
  - validateTokenScopes()        → Validar permissões

NOVAS ROTAS DO SERVIDOR (src/server.js):
  GET  /api/stream/scopes             → Verificar permissões
  GET  /api/stream/auth-url           → URL para solicitar permissões
  GET  /auth/callback                 → Callback OAuth
  POST /api/stream/create-clip        → Criar clip
  GET  /api/stream/info               → Informações da stream
  POST /api/stream/update-title       → Atualizar título
  GET  /api/stream/search-categories  → Buscar categorias
  POST /api/stream/update-category    → Atualizar categoria
  POST /api/stream/run-commercial     → Rodar comercial

WIDGET NO DASHBOARD:
  - Verificação automática de permissões
  - Botão para solicitar novas permissões
  - 5 botões de ação (clip, comercial, título, categoria, atualizar)
  - Modal para entrada de dados (título, categoria, duração)
  - Status visual de cada ação
  - Atualização automática a cada 30 segundos

  🐛 TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: Botões desabilitados
SOLUÇÃO: Solicite novas permissões clicando no botão 🔐

PROBLEMA: "Erro ao criar clip"
CAUSA: Stream não está ao vivo
SOLUÇÃO: Entre ao vivo primeiro

PROBLEMA: "Categoria não encontrada"
CAUSA: Nome incorreto ou em português
SOLUÇÃO: Use nomes em inglês (ex: "Just Chatting")

PROBLEMA: "Token inválido"
SOLUÇÃO: Delete .twitch-tokens.json e solicite novas permissões
