🎯 PASSO A PASSO COMPLETO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALAÇÃO:
   
   npm install

2. CONFIGURAÇÃO (.env):
   
   TWITCH_CLIENT_ID=seu_id
   TWITCH_CLIENT_SECRET=seu_secret
   TWITCH_CHANNEL=seu_canal

3. AUTENTICAÇÃO:
   
   npm start
   http://localhost:3000/auth/login
   (Autorize e reinicie)

4. ⭐ TESTE (OBRIGATÓRIO):
   
   http://localhost:3000/test
   
   Clique em "Testar Áudio"
   
   ✅ Funcionou? Continue!
   ❌ Não? Veja os logs e erro na tela

5. CONFIGURE OBS:
   
   - Browser Source
   - URL: http://localhost:3000/player.html
   - 800x600
   - ✅ Controlar áudio via OBS
   - Botão direito > Interagir > Ativar Áudio

6. USE NO TWITCH:
   
   !fala Olá, teste de áudio!

❓ PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Áudio não toca"

   1. Teste em: http://localhost:3000/test
   2. Funciona lá? Problema é no OBS
   3. No OBS: Botão direito > Interagir > Ativar Áudio
   4. Ainda não? Use player nativo: /player-native.html

❌ "Bot não conecta"

   1. Fez login OAuth?
      → http://localhost:3000/auth/login
   2. Arquivo .env configurado?
      → Verifique CLIENT_ID, CLIENT_SECRET, CHANNEL
   3. Execute: .\diagnostico.ps1

❌ "Comando !fala não funciona"

   1. Bot está conectado?
      → Veja logs: "Bot conectado"
   2. Escreveu corretamente?
      → !fala (não !speak)
   3. Está em cooldown?
      → Aguarde 3 segundos
